## Quickstart

### Build and test cJSON

```bash
# Clone with submodule
git clone --recurse-submodules https://github.com/BitVortex/OSQAr-cJSON.git
cd OSQAr-cJSON

# Run full qualification pipeline
./build-and-test.sh all
```

### Rebuild documentation

```bash
# Install dependencies
python3 -m pip install -r requirements-docs.txt

# Build Sphinx HTML (with PlantUML diagrams)
python3 -m sphinx -b html -W . _build/html

# Or without diagrams (offline/CI-friendly — use plain sphinx-build)
OSQAR_NO_DIAGRAMS=1 python3 -m sphinx -b html . _build/html

# Verify traceability (with cJSON custom need-ID prefixes)
osqar traceability _build/html/needs.json \
  --test-prefix VER_ --code-prefix IMPL_
```

### Generate shipment package

```bash
# Full shipment prepare via OSQAr CLI (v0.7.0)
osqar shipment prepare --project . \
  --test-prefix VER_ --code-prefix IMPL_ \
  --skip-verification
```
